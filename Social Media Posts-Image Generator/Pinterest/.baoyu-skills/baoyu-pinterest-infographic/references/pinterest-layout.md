# Pinterest Infographic Layout Guide

## Overview

This guide defines the standard Pinterest infographic layout for the Thin Hair Growth Guide brand. Uses bento grid + IKEA manual style for medical-trust educational content.

## Standard Bento Grid Structure

Portrait orientation (2:3 ratio) with 7 cells arranged in a modular grid:

```
┌─────────────────────────────────┐
│  Cell 1: TITLE (Hero, 2x1)     │
│  Headline + Subhead + Icon      │
├───────────────┬─────────────────┤
│  Cell 2       │  Cell 3         │
│  (1x1)        │  (1x1)          │
├───────────────┼─────────────────┤
│  Cell 4       │  Cell 5         │
│  (1x1)        │  (1x1)          │
├───────────────┴─────────────────┤
│  Cell 6: KEY STAT (2x1)        │
│  Large number + context         │
├─────────────────────────────────┤
│  Cell 7: FOOTER (2x1)          │
│  Takeaway + Logo + URL          │
└─────────────────────────────────┘
```

## Cell Specifications

### Cell 1: Title (Hero, top, full width)
- **Purpose**: Introduce topic with compelling headline
- **Content**: Main headline + subhead + icon
- **Style**: Bold sans-serif, dark navy (#002444)
- **Icon**: Positioned to the right of title text

### Cells 2-5: Content Grid (1x1 each)
- **Purpose**: Present key causes/concepts
- **Layout**: 2x2 grid with clear boundaries
- **Content per cell**:
  - Header (dark navy)
  - Subhead (context)
  - Icon (minimal line art)
- **Visual hierarchy**: Consistent padding, varied backgrounds

### Cell 6: Key Stat (full width)
- **Purpose**: Highlight impactful statistic
- **Content**: Large number + context text
- **Style**: 
  - Number: Large, bold, dark navy (#002444)
  - Accent: Red (#b91c1c) underline or line
  - Context: Smaller text below

### Cell 7: Footer (full width)
- **Purpose**: Branding + call-to-action
- **Content**:
  - Takeaway message
  - Logo (white on dark navy strip)
  - URL (small text)
- **Style**: Clean, professional

## Cell Design Rules

### Boundaries
- Thin black lines or subtle gaps between cells
- Each cell has own background (white or light gray variation)
- Consistent padding inside each cell (16-24px)

### Typography
- **Cell headers**: Bold, dark navy (#002444), 18-24px
- **Subheads**: Regular, dark gray (#374151), 14-16px
- **Labels**: Clear, sans-serif, 12-14px
- **Statistics**: Large, bold, 48-64px

### Icons
- **Style**: Minimal line art (IKEA manual)
- **Color**: Black (#000000)
- **Size**: 48-64px
- **Treatment**: Simple, no fills or shading

## Visual Hierarchy

1. **Title cell** (largest, full width)
2. **Stat cell** (full width, large number)
3. **Content cells** (equal size, balanced)
4. **Footer** (branding, CTA)

## Responsive Considerations

- **Mobile-first**: Large text, clear icons
- **Scannable**: Quick visual hierarchy
- **Pinterest feed**: Portrait orientation optimized
- **Pin size**: 1080x1620px (2:3 ratio)

## Example Content Flow

### For "Causes" Infographic
1. Title: "Why Is Your Hair Thinning?"
2. Cell 2-5: 4 main causes with icons
3. Cell 6: Key statistic (e.g., "85% of men by 50")
4. Cell 7: CTA + branding

### For "Treatments" Infographic
1. Title: "How to Thicken Your Hair"
2. Cell 2-5: 4 treatment approaches
3. Cell 6: Success statistic
4. Cell 7: CTA + branding
