How it works

drop everything · AI handles the rest
Drop all your bank files in one batch — chequing CSV, every credit-card CSV, screenshots, anything. The AI reads the filenames and contents to figure out which account each file is from.

Auto-deduplication: when you pay your Visa from chequing, that's one financial event but two CSV rows (a withdrawal in chequing, a payment in CC). The AI detects these inter-account transfers and skips both — only real spending and income survive.

🛠 How to set up the n8n workflow

Build this once in n8n, then paste the webhook URL above. The OpenRouter key lives only on n8n — your browser never sees it.

  1. Webhook node — Method: POST. Path: your choice. If you set a bearer token above, configure Authentication = "Header Auth" with header Authorization and expected value Bearer <your-token>. Leave auth off if the field above is empty.
  2. HTTP Request node — POST to https://openrouter.ai/api/v1/chat/completions. Headers: Authorization: Bearer {{ $env.OPENROUTER_KEY }}, Content-Type: application/json, HTTP-Referer: https://budgetos.app, X-Title: BudgetOS. Body: pass through the incoming request body verbatim ({{ $json.body }}).
  3. Respond to Webhook node — Return the HTTP node's response JSON unchanged. Must include choices[0].message.content.

App sends → { model, messages, response_format?, max_tokens? }
n8n returns → { choices: [{ message: { content: string } }] }
