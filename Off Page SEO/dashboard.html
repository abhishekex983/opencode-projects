Setup Guide — Track Backlinks in 5 Minutes
Download the checker, run it on your machine, see results here.
▾
  1. Create your Google Sheet from the template. Download the pre-built template so the tab names are correct automatically (a single typo in the tab name will break the crawler).
    📄 Download Template (XLSX) ~6 KB · has URLs + Results tabs preset
    In Google Sheets: File → Import → Upload, drop in the XLSX, pick "Replace spreadsheet". Paste your backlink URLs under the url column, then Share → Anyone with the link → Viewer.
  2. Download the Backlink Checker tool.
    ⬇ Download Tool (ZIP) Windows / Mac / Linux · requires Python 3.10+
    Unzip the folder anywhere on your computer. Follow README.txt inside for step-by-step setup.
  3. Fill in config.json inside the downloaded folder:
    • target_domain — your root domain (e.g. example.com)
    • sheet_id — the ID in your Google Sheet URL
    • sheets_api_key — from Google Cloud Console
    • apps_script_url — deploy apps_script.js as a Web App (see README)
  4. Run the checker. Double-click Setup.bat once (installs Python libs), then double-click Run Check.bat every time you want to crawl. Takes ~2-3 seconds per URL.
  5. View your results on this dashboard. Paste your Sheet ID and API Key below, then click Load. Stats and link status appear in the cards and table. Click Refresh any time after a new crawl.
💡 Tip: For small URL lists (<500), you can skip steps 2–4 and use the Run Check button below — it triggers the same crawler via our hosted n8n workflow. For large lists (thousands of URLs), run locally for faster results.

How Order Tracker Works
Use this when you've placed link orders but don't yet have the exact placement URL.
▾
  1. Enter your domain (where the backlink should be pointing to).
  2. Paste the publisher root domains (one per line) where you've ordered placements.
  3. Click Find Links. The tool queries DataforSEO's backlink index for each publisher domain and reports any live links to your site.
  4. Cost: ~$0.02 per domain checked. Cached for 30 days.
Note: DataforSEO's index updates every few days. Brand new placements (<48 hours old) may not yet appear.
