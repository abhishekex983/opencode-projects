One-Time Setup

Connect a free Firebase project to enable login & real-time sync across all your devices.

1

Go to console.firebase.google.com and create a new project (it's free)

2

Go to Build → Authentication → Sign-in method and enable Email/Password

3

Go to Build → Realtime Database → Create Database (pick any location, start in test mode)

4

Click gear icon → Project settings, scroll to "Your apps", click Web (</>), register an app, then copy the config values below

This setup is one-time per device. After this, you just use email & password to sign in.
